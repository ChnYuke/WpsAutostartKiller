## 阅读顺序建议

1. 先看 [手动操作手册.md](手动操作手册.md) 的**第 1 章**，搞清楚 WPS 的自启到底是怎么运作的（三条机制、为什么删条目无效）
2. 再看**第 3 章**（备份清单）和**第 5、6、7、4 章**（四道闸），这是核心
3. 想连升级一起封，看**第 12 章**
4. 动手前把 [快速参考卡片.md](快速参考卡片.md) 打印出来

## 几处容易踩的坑（手册里都有详述）

- `icacls` 的简写 `W` 会把 `READ_CONTROL` 一起 DENY，导致文件读不了、程序起不来 —— 必须用精确权限位
- 判断命令行参数不能用子串包含，必须 token 精确匹配（`/prometheus`、`from=taskbar` 都栽过）
- 守卫壳编译时忘了 `/win32icon`，图标会变成默认程序图标
- `wpsUpdateStatus = UpdateError` 证明不了升级通道被封，它只证明更新器跑不起来
- 备份命令用的是固定文件名，**只能在动手改之前做一次**
